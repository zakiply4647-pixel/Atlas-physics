# ATLAS PHYSICS — عالم الفيزياء

مشروع واجهة تعليمية عربية للسنة الرابعة متوسط في الجزائر.

## الملفات
- `index.html`: هيكل الصفحات.
- `styles.css`: التصميم المتجاوب، البطاقات، الألوان، الوضع الفاتح والداكن.
- `app.js`: الدروس والتمارين والاختبارات ومحاكاة قانون أوم والقوانين وحفظ التقدم محليًا.

## التشغيل
افتح `index.html` في المتصفح. لا توجد حزم مطلوبة.

## GitHub Pages
ارفع الملفات الثلاثة إلى جذر الفرع `main`، ثم افتح Settings → Pages واختر Deploy from a branch، والفرع `main` والمجلد `/(root)`.

الرابط المتوقع:
https://zakiply4647-pixel.github.io/Atlas-physics/

## ملاحظات
- التقدم محفوظ محليًا في المتصفح وليس في حساب سحابي.
- المخبر محاكاة تعليمية وليس توصيلًا كهربائيًا حقيقيًا.
- هذا إصدار أولي؛ راجع المحتوى مع الكتاب والوثائق الرسمية الجزائرية قبل اعتباره تغطية كاملة للمنهاج.
